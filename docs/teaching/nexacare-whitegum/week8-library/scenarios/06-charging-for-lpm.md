# Scenario 6 — Who pays for the project management?

**Matter:** Group C — Meridian Property, CBD Development Project
**Raised by:** Practice management

The firm has begun running matters with a formal LPM discipline: a scoping
workshop, a task plan, weekly tracking, and a monthly client report. The time
spent on these activities is recorded against the matter and billed at the
responsible lawyer's rate.

A client has queried the line items:

> "I'm being charged $600 an hour for someone to update a spreadsheet about
> my own matter. I didn't ask for weekly reports. Is this legal work?"

Internally the position is contested. One view is that LPM reduces total cost
and the client benefits, so it is properly chargeable. Another is that it is
firm overhead and should be absorbed into rates. A third is that it should be
chargeable only where the client has agreed to it in the engagement.

The letter of engagement is silent on the point.
